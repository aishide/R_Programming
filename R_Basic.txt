R Language : 

* used for statistical computing and graphical presentation.
* common use is to analyze and visualize data.


Syntax : 
* To output text in R, use single or double quotes
* To output numbers, just type the number (without quotes)


Comments :
* Comments starts with a #
* No multiline comments here


Variables :
* Variables are containers for storing data values
* To assign a value to a variable, use the <- sign
