## 🗂️ Interactive Module Explorer

Click on any module below to inspect the topics, datasets, and R techniques covered inside:

<details open>
<summary><b>📂 01_Basics_and_Data_Structures</b> — <i>Core R Foundations & Vectorization</i></summary>
<br/>

* **Data Structures:** Atomic vectors, matrices, multidimensional arrays, named lists, ordered factors, and `data.frame` vs. `tibble`.
* **Functional Programming:** Vectorized operations with `apply()`, `lapply()`, `sapply()`, `mapply()`, and `purrr::map()`.
* **Control Flow:** Custom S3 functions, error handling (`tryCatch`), and defensive programming.
</details>

<details>
<summary><b>📂 02_Data_Wrangling_Tidyverse</b> — <i>High-Speed Pipelines & Reshaping</i></summary>
<br/>

* **Data Transformation:** Chained `%>%` and native `|>` pipelines using `filter()`, `mutate()`, `summarise()`, and `across()`.
* **Reshaping & Joins:** Wide-to-long pivoting (`pivot_longer`, `pivot_wider`), relational joins, and regex cleaning with `stringr`.
* **Performance:** Benchmarking `dplyr` against `data.table` for large-scale tabular datasets.
</details>

<details>
<summary><b>📂 03_Data_Visualization_ggplot2</b> — <i>Layered Grammar of Graphics</i></summary>
<br/>

* **Distributions & Comparisons:** Ridgeline plots, raincloud plots, violin-box hybrids, and faceted histograms.
* **Multivariate & Spatial:** Correlation heatmaps (`corrplot`), bubble scatter plots, and multi-panel dashboards with `patchwork`.
* **Custom Aesthetics:** Publication-ready custom `theme()` templates, colorblind-safe palettes (`viridis`), and animated plots (`gganimate`).
</details>

<details>
<summary><b>📂 04_Statistical_Analysis</b> — <i>Inference, Distributions & Testing</i></summary>
<br/>

* **Probability & Distributions:** Normal, Binomial, Poisson, and Chi-Square simulations (`dnorm`, `pnorm`, `qnorm`, `rnorm`).
* **Hypothesis Testing:** Student's t-tests, one-way/two-way ANOVA, Kruskal-Wallis, and Shapiro-Wilk normality diagnostics.
* **Moments & Diagnostics:** Skewness, kurtosis (`moments`), Z-score outlier detection, and confidence interval estimation.
</details>

<details>
<summary><b>📂 05_Machine_Learning_in_R</b> — <i>Predictive Modeling & Validation</i></summary>
<br/>

* **Supervised Learning:** Multiple linear regression, regularized regression (`glmnet`), Decision Trees, Random Forests, and Gradient Boosting (`gbm`).
* **Unsupervised Learning:** K-Means clustering, Hierarchical clustering, and Principal Component Analysis (PCA) biplots.
* **Model Evaluation:** K-fold cross-validation (`caret`), ROC-AUC curves, confusion matrices, and feature importance plots.
</details>

## 💻 Featured `ggplot2` Visualization Snippet

Here is an example of the clean, publication-grade visualization architecture practiced inside this repository:

```r
library(tidyverse)

# High-contrast, layered ggplot2 pipeline
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl), fill = factor(cyl))) +
  geom_point(size = 4, alpha = 0.85, shape = 21, color = "#0D1117", stroke = 1.2) +
  geom_smooth(method = "lm", se = TRUE, alpha = 0.15, linewidth = 1.1) +
  scale_color_manual(values = c("#38BDF8", "#A855F7", "#10B981")) +
  scale_fill_manual(values  = c("#38BDF8", "#A855F7", "#10B981")) +
  labs(
    title    = "Vehicle Weight vs. Fuel Efficiency",
    subtitle = "Stratified by Engine Cylinders with 95% Confidence Bands",
    x        = "Weight (1,000 lbs)",
    y        = "Miles Per Gallon (MPG)",
    fill     = "Cylinders",
    color    = "Cylinders",
    caption  = "Source: R datasets::mtcars | Styled with ggplot2"
  ) +
  theme_minimal(base_size = 13) +
  theme(
    plot.title       = element_text(face = "bold", size = 16),
    plot.subtitle    = element_text(color = "#6B7280"),
    panel.grid.minor = element_blank(),
    legend.position  = "top"
  )
```

## ⚡ Quick Start

Clone the repository and restore the environment in **RStudio**:

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/R-Programming-Practice.git

# 2. Enter the project directory
cd R-Programming-Practice
```

Run the setup script inside your **R Console** to install all required packages:

```r
packages <- c(
  "tidyverse", "data.table", "ggplot2", "plotly", "patchwork",
  "corrplot", "moments", "caret", "randomForest", "gbm", "rmarkdown"
)

install.packages(setdiff(packages, rownames(installed.packages())))
```
