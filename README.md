## 🚀 Getting Started

1. Install **R** on your system.
2. Install **RStudio** (optional but recommended).
3. Clone this repository:

```bash
git clone <repository-url>
```

4. Open the `.R` files in RStudio or any R-compatible environment.
5. Run the programs and experiment with the code.
