## 🚀 About This Repository

Welcome to my **R Programming Practice Repository**! This space serves as a structured sandbox for mastering statistical computing, data manipulation, visualization, and machine learning workflows in R.

Whether it's cleaning messy datasets, running hypothesis tests, or building classification models, every script here is documented for clarity and reproducibility.

---

## 🗂️ Repository Structure

```text
📦 R-Programming-Practice
 ┣ 📂 01_Basics_and_Data_Structures   # Vectors, matrices, lists, factors & data frames
 ┣ 📂 02_Data_Wrangling_Tidyverse     # dplyr pipelines, tidyr reshaping & stringr
 ┣ 📂 03_Data_Visualization_ggplot2   # Custom themes, distributions, scatter & heatmaps
 ┣ 📂 04_Statistical_Analysis         # Normal distribution, Z-scores, ANOVA & correlation
 ┣ 📂 05_Machine_Learning_in_R        # Regression, Random Forest, GBM & model evaluation
 ┗ 📜 README.md
```

## 🛠️ Tech Stack & Core Libraries

<div align="center">

| Category | Packages & Tools | Purpose |
| :--- | :--- | :--- |
| **Data Manipulation** | `dplyr`, `tidyr`, `data.table`, `readr` | Filtering, grouping, joins, and fast I/O |
| **Visualization** | `ggplot2`, `plotly`, `corrplot`, `patchwork` | Publication-grade static & interactive charts |
| **Statistics** | `stats`, `moments`, `car`, `MASS` | Skewness, kurtosis, distributions & hypothesis tests |
| **Machine Learning** | `caret`, `randomForest`, `gbm`, `e1071` | Classification, regression, tuning & cross-validation |
| **Reporting** | `rmarkdown`, `knitr`, `shiny` | Reproducible notebooks & interactive dashboards |

</div>

## ⚡ Quick Start

Clone this repository and open the project in **RStudio**:

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/R-Programming-Practice.git

# Navigate to the directory
cd R-Programming-Practice
```

Install the core dependencies in your R console:

```r
install.packages(c("tidyverse", "ggplot2", "caret", "randomForest", "moments", "corrplot"))
```
