## 💻 Sample `ggplot2` Pipeline

A quick look at the clean, layered visualization style used inside this repository:

```r
library(tidyverse)

# Layered visualization with custom aesthetics
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3.5, alpha = 0.85) +
  geom_smooth(method = "lm", se = FALSE, linetype = "dashed") +
  scale_color_manual(values = c("#4F39FF", "#815BF1", "#00D26A")) +
  labs(
    title = "Fuel Efficiency vs. Vehicle Weight",
    subtitle = "Grouped by Cylinder Count with Linear Trendlines",
    x = "Weight (1000 lbs)",
    y = "Miles Per Gallon (MPG)",
    color = "Cylinders"
  ) +
  theme_minimal(base_size = 13)
```

## ⚡ Quick Start

Clone this repository and launch the project in **RStudio**:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/R-Programming-Practice.git

# Navigate to the directory
cd R-Programming-Practice
```

Install all required packages in your R console:

```r
install.packages(c("tidyverse", "ggplot2", "plotly", "caret", "randomForest", "moments", "corrplot", "patchwork"))
```
